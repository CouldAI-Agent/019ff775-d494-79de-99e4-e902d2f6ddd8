# تطبيق مساعد المحاضرات (Lecture Assistant)

تطبيق ذكي مبني بـ Flutter مصمم لمساعدة الطلاب على فهم المحاضرات الأكاديمية المعقدة وتلخيصها بأسلوب مبسط ومباشر.

## المميزات

*   **تلخيص ذكي:** إدخال نص المحاضرة أو الملاحظات للحصول على ملخص مكثف لأهم النقاط.
*   **شرح مبسط:** إعادة صياغة المفاهيم المعقدة بطريقة سهلة الفهم وأفضل من الأسلوب الأكاديمي المعقد.
*   **واجهة بسيطة:** تصميم نظيف وسهل الاستخدام يركز على المحتوى التعليمي.
*   **دعم اللغات:** مصمم للتعامل مع النصوص الأكاديمية بكفاءة.

## التقنيات المستخدمة

*   Flutter
*   Dart
*   Material Design 3

## كيفية التشغيل

1. تأكد من تثبيت Flutter SDK.
2. قم بتشغيل `flutter pub get` لتثبيت الحزم.
3. قم بتشغيل التطبيق عبر `flutter run`.

## حول CouldAI
تم إنشاء هذا التطبيق باستخدام [CouldAI](https://could.ai)، وهو منشئ تطبيقات ذكاء اصطناعي للتطبيقات عبر الأنظمة الأساسية يقوم بتحويل الأوامر إلى تطبيقات أصلية حقيقية لأنظمة iOS وAndroid وWeb وDesktop باستخدام وكلاء ذكاء اصطناعي مستقلين يقومون بتصميم وبناء واختبار ونشر وتطوير تطبيقات جاهزة للإنتاج.
